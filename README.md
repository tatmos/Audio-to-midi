# SE-Editor

Web上で動作する効果音エディタです。波形ファイルをアップロードし、切り出し、加工した波形を作成できます。

## 機能

- **波形アップロード**: 音声ファイル（WAV、MP3など）をアップロード
- **2つの元波形表示**: 
  - 元波形を2つ指定できます
  - それぞれの波形の利用したい部分を指定できます
    - 波形表示の両端をドラッグして、開始位置・終了位置を指定します
- **2トラック表示**: 
  - トラック1: 元波形1の加工後の波形表示
  - トラック2: 元波形2の加工後の波形表示
  - 波形は、リージョン（矩形）の中に表示されます
  - リージョンはAltドラッグで複製が可能です
  - 編集対象を選択できます
  - リージョンの波形の再生開始位置をドラッグで変更できます
  - リージョンのフェードイン・フェードアウトを変更できます
    - リージョンの左上のアンカーをドラッグするとフェードイン区間の指定
    - リージョンの右上のアンカーをドラッグするとフェードアウト区間の指定
  - リージョンの再生ピッチを変更できます（ピッチシフト）
  - リージョンの再生範囲を変更できます（タイムストレッチ）
    - リージョンの右下のアンカーをドラッグすると表示範囲を伸縮させることができます
  - ステレオ波形の場合は、各リージョンに2行で表示
  - トラックにピッチトランスポーズとcent単位を指定できる数値入力UIがあります。
- **Analyzer:
  - Mix後の周波数表示
- **3-Band MultiBand Up/Down Comp**: 
  - Mix後の波形にH,M,Lの3つの帯域それぞれにコンプレッサーをかけることができます
  - OTTのような3行のUI
  - 全体の効果のMix割合をつまみでを指定できます
- **空間デザイン**:
  - 各トラックの音の再生位置をX-Z平面（水平面）でドラッグして指定できます
  - 中央から遠くに離れると残響効果が付与されます
  - 残響効果のMix割合をつまみでを指定できます
- **プレビュー再生**: 
  - 2トラックを同時にループ再生して全体確認ができます
  - 再生中に波形をクリックするとその位置に再生からの再生を継続します 
- **ファイル保存**: 加工された波形をWAVファイルとして保存

## 使い方

1. 「波形をアップロード」ボタンから音声ファイルを選択
2. 各種パラメータを編集して調整
3. 「再生」ボタンでプレビューを確認
4. 「ファイル保存」ボタンで加工された波形を保存

## 技術仕様

- HTML5
- CSS3
- JavaScript (ES6+)
- Web Audio API

## ブラウザ要件

- Chrome、Firefox、Edge、Safariなどのモダンブラウザ
- Web Audio APIをサポートしている必要があります
